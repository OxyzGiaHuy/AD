\section{Related Work}
\subsection{Few-Shot Industrial Anomaly Detection}
Memory-bank methods such as PatchCore~\cite{patchcore2021} compare test patch features against stored normal references and have become strong industrial AD baselines. AnomalyDINO~\cite{anomalydino2024} extends this idea to frozen DINOv2 features for few-shot AD, showing that foundation patch embeddings can support strong image- and pixel-level anomaly ranking. These methods are accurate but retain reference features at inference time.

\subsection{Frozen-Feature Subspace Anomaly Detection}
SubspaceAD~\cite{subspacead2026} shows that frozen DINOv2 patch features can be represented by normal subspaces, reducing the need for large memory banks. Our ranking component follows this family: patch residuals to a normal PCA/subspace model define the raw anomaly score. We explicitly do not claim PCA residual scoring as new; instead, we use it as a low-storage base detector around which reliability mechanisms can be studied.

\subsection{Calibration, Robustness, and Reliability}
Calibration maps model scores to probabilities whose confidence matches empirical frequency. In few-shot AD, this is difficult because support data are normal-only and anomaly distributions are open-ended. Recent reliability studies have quantified poor ECE and FGSM fragility for DINOv2-based few-shot AD~\cite{khan2025calibration}. We therefore treat calibration and robustness as first-class evaluation axes, but we avoid claiming adversarial robustness: our FGSM results are diagnostic and show severe fragility.

\subsection{Conformal Prediction and Gated Routing}
Conformal prediction converts nonconformity scores into p-values under exchangeability assumptions and can provide false-alarm-style diagnostics. Gated-expert models, including recent SAGE-style architectures~\cite{Thai_2026_CVPR}, motivate routing between safe shared paths and specialized experts. Our work borrows this routing perspective but does not copy a segmentation architecture. The main reliability view is a fixed LOIO conformal route; gated and weighted variants are reported as ablations and diagnostics.
